This toolbox is designed to help implement the SatGEM-2 data onto SWOT swaths. \
\
The required SatGEM-2 field is available at: https://zenodo.org/uploads/18889113 under the file name GEM_smoothed_2000dbar_for_SWOT.nc and will be required for this toolbox to work. You will also either need to have your own AVISO account, or SWOT swath files saved somewhere. \
\
There are example notebooks under the 'how_to_SWOTGEM.ipynb' which show how some of the tools are used. \\
